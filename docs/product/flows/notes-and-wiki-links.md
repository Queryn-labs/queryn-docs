# Конспекты и wiki-ссылки

Конспект — Markdown-файл в области <code>notes/</code>. В открытом проекте он
создаётся, редактируется и сохраняется через <code>ProjectNavigator</code>,
<code>useProjectMaterials</code>, <code>NoteEditor</code> и <code>MarkdownEditor</code>.

Wiki-ссылка имеет форму <code>[[Название конспекта]]</code>. Редактор предлагает
названия из текущего дерева материалов, а переход по ссылке разрешает название
или проектный путь. Разрешение и список найденных связей выполняются по данным
текущего проекта, а не по глобальному индексу компьютера.

## Поток

~~~mermaid
flowchart TD
  Project([Открытый проект]) --> Materials["Режим Проект"]
  Materials --> NewNote["Конспект"]
  NewNote --> Create["createNote"]
  Create --> Tree["Обновить дерево notes"]
  Tree --> Editor["NoteEditor + MarkdownEditor"]
  Editor --> Type["Ввести Markdown"]
  Type --> LinkStart["Набрать [[ ]]"]
  LinkStart --> Suggestions["Подсказки названий и путей"]
  Suggestions --> Insert["Вставить [[target]]"]
  Insert --> Save["Сохранить"]
  Save --> Update["updateNoteDocument"]
  Update --> Disk["Файл notes/*.md"]
  Editor --> Click["Нажать разрешённую wiki-ссылку"]
  Click --> Resolve{"Конспект найден?"}
  Resolve -->|да| Open["Открыть целевой конспект"]
  Resolve -->|нет| Missing["Сообщение: конспект не найден"]
~~~

При создании <code>createNote</code> формирует frontmatter с идентификатором,
названием и временами создания и изменения. <code>updateNoteDocument</code>
обновляет название, содержимое и время изменения, сохраняя файл Markdown в
проекте. Кнопка сохранения и сочетание <code>Ctrl/Cmd+S</code> используют один
и тот же путь.

Ссылки собираются также через <code>listProjectLinks</code>. Для wiki-ссылки
runtime сопоставляет заголовок, относительный путь и slug. Фрагмент после
<code>#</code> в цели не участвует в поиске. Поддержка полноценной навигации по
заголовкам и блокам не заявляется.

## Точки потока

| Точка | Экран/действие | Ошибка/деградация |
| --- | --- | --- |
| Вход | В <code>ProjectNavigator</code> выбрать <code>Проект</code> | При ошибке загрузки дерева показывается сообщение, проект остаётся открытым |
| Новый конспект | Нажать <code>Конспект</code>, ввести название и подтвердить | Пустое название закрывает черновик. Ошибка создания остаётся всплывающим сообщением |
| Редактор | <code>NoteEditor</code> показывает заголовок, метаданные и тело Markdown | Содержимое редактируется локально до сохранения и отмечается как несохранённое |
| Wiki-ввод | <code>MarkdownEditor</code> предлагает элементы из текущих <code>notes</code> | При отсутствии подходящих элементов подсказка не появляется |
| Сохранение | <code>updateNoteDocument</code> записывает название и тело в исходный файл | Ошибка записи оставляет изменённое состояние и показывает сообщение |
| Смена материала | Выбрать другой конспект в дереве | При несохранённых изменениях показывается подтверждение перехода |
| Переход по ссылке | Нажать подсвеченную <code>[[...]]</code> | Если цель не разрешилась, показывается <code>Конспект по ссылке не найден.</code> |

## Граница реализации

В текущем редакторе wiki-ссылки ведут только на конспекты. Для файлов
используется обычная Markdown-ссылка на путь <code>assets/...</code>, а не
обещание универсального формата wiki-embeds. Backlinks и отдельный экран графа в
этом потоке не реализованы.
