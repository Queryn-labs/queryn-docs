# Архитектура desktop-клиента

`osnova-desktop` использует Electron, React и TypeScript через `electron-vite`.

## Процессы

- Main: жизненный цикл приложения, native dialogs, project и file services.
- Preload: узкий IPC bridge, доступный renderer.
- Renderer: React-приложение, pages, widgets, features, entities и shared UI.

## Сервисы

- `project-service`: создание, открытие и чтение папок проекта. Открытие
  произвольной непустой папки, не являющейся проектом, показывает план
  усыновления (adoption): какие служебные папки будут созданы и какие занятые
  зарезервированные имена затронуты; подтверждение создаёт манифест и
  отсутствующие каталоги, не трогая существующие файлы.
- `file-service`: безопасные файловые операции внутри проекта.
- `settings-service`: локальные настройки desktop-клиента.
- `plugin-service`: зарезервированная граница для загрузки плагинов.
- `ai-service`: интеграция с локальным runtime: диалоговый агент
  Queryn Intelligence с инструментами, потоковой выдачей, промежуточными
  абзацами и переключателем полной памяти сессии; сообщения рендерятся как
  Markdown с санитизацией.

## Раскладка главной рабочей области

Шапка приложения остаётся частью стабильной оболочки. Содержательная область
главной страницы строится из выбранной локальной раскладки. Раскладка хранит
упорядоченные экземпляры виджетов, их ширину и параметры. Интерфейс разрешает
типы виджетов через явный реестр и показывает безопасное состояние для временно
недоступного типа.

Модальные сценарии виджетов выводятся через единый портал оболочки. Их состояние
остаётся у вызывающего виджета, а затемнение и диалог располагаются в глобальном
слое рабочей области и не зависят от размеров или сетки виджета.

Список проектов, его заголовок, поиск, карточки и действия принадлежат системному
виджету `osnova.projects`. Его данные поступают из списка недавних проектов.
Раскладка и параметры виджетов являются локальными настройками настольного клиента и
не входят в `osnova.json`. Содержательные результаты виджетов могут сохраняться
как артефакты проекта, сами элементы интерфейса артефактами не являются.
