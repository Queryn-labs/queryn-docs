# Установка расширения и разрешения

Desktop содержит компонент <code>ToolManager</code>, а preload публикует
операции установки, обновления, отката и подключения расширения. При этом
текущая навигация не даёт перейти в <code>ToolManager</code> из доступного
пользовательского пути, и окно подключения не содержит отдельного выбора
разрешений. При установке из этого компонента передаётся
<code>allowUnsigned: true</code>, поэтому режим разработчика фактически
разрешает неподписанный пакет. Это важная граница доверия, а не безопасный
каталог расширений.

## Поток

~~~mermaid
flowchart TD
  Shell["AppShell: activeView = tools, маршрут предусмотрен кодом"] -.-> Manager["ToolManager: компонент"]
  Manager -.-> Pick["selectExtensionPackage"]
  Pick -.-> Install["installExtension({ packagePath, allowUnsigned: true })"]
  Install --> Verify["Runtime: проверка пакета, manifest, integrity, signature"]
  Verify --> Staging["Staging и активация версии"]
  Staging --> List["listExtensions / listOperations"]
  List --> Project{"Открыт проект?"}
  Project -->|нет| Unavailable["Подключение к проекту не выполняется"]
  Project -->|да| Connect["connectExtension: версия + весь manifest.permissions"]
  Connect --> Lock["Запись project lock и локального подключения"]
  Lock --> Ready["Операции расширения видны runtime"]
  Ready --> Disconnect["disconnectExtension"]
  Staging --> Rollback["rollbackExtension({ extensionId, version })"]
~~~

Пунктиром обозначен путь, который описан компонентами, но не доступен из
текущей навигации. На уровне runtime установка всё равно проверяет размер,
формат, целостность, подпись и совместимость host. Подключение к проекту
проверяет диапазон версии и то, что запрошенные разрешения объявлены в
манифесте, но desktop не даёт пользователю уменьшить список разрешений.

## Точки потока

| Точка | Экран/действие | Ошибка/деградация |
| --- | --- | --- |
| Вход | В коде <code>AppShell</code> умеет выбрать глобальный вид <code>tools</code> | Текущая renderer-навигация не содержит кнопки, которая устанавливает этот вид |
| Выбор пакета | <code>selectExtensionPackage</code> открывает системный выбор файла | Отмена не меняет состояние |
| Установка | <code>ToolManager</code> передаёт пакет в <code>installExtension</code> с <code>allowUnsigned: true</code> | Такой путь предназначен для разработки и принимает unsigned-пакет, если остальная валидация проходит |
| Проверка | Runtime проверяет формат <code>osnova-extension-package/1</code>, manifest, размер, целостность, подпись и безопасные пути | Ошибка проверки не активирует пакет и возвращается в сообщение |
| Версии | Новая версия устанавливается рядом, а активная версия обновляется через состояние runtime | Откат доступен как API <code>rollbackExtension</code>, отдельного рабочего сценария в доступной навигации нет |
| Разрешения | В карточке расширения отображается <code>manifest.permissions</code> | Переключателей отдельных разрешений или диалога подтверждения нет |
| Подключение | Для проекта вызывается <code>connectExtension</code> с выбранной версией и всем массивом разрешений манифеста | Без открытого проекта компонент сообщает, что проект нужно открыть |
| Политика | Runtime проверяет диапазон версии и объявленные разрешения, а проект хранит локальную связь | Установка не равна подключению к проекту; подключение может быть отклонено политикой |
| Отключение | <code>disconnectExtension</code> выключает связь расширения с проектом | Установленный пакет при этом не удаляется |

## Матрица разрешений

| Разрешение | Что оно означает в контракте |
| --- | --- |
| <code>project:read</code> | Читать данные проекта через разрешённый контекст |
| <code>artifact:read</code> | Читать артефакты |
| <code>artifact:create</code> | Создавать артефакты |
| <code>network:use</code> | Использовать сетевой доступ |
| <code>models:use</code> | Использовать модели |
| <code>models:install</code> | Устанавливать модели |
| <code>compute:gpu</code> | Запрашивать графический вычислитель |
| <code>native:execute</code> | Выполнять нативный процесс |
| <code>external:apps</code> | Взаимодействовать с внешними приложениями |
| <code>secrets:read</code> | Читать секреты через предусмотренный механизм |
| <code>background:run</code> | Работать в фоне для длительного жизненного цикла |

Эти разрешения не являются обещанием конкретной кнопки или возможности в
desktop. Их применение зависит от manifest, типа runtime, операции и policy
engine. Каталог с рецензией, безопасный мастер разрешений и полноценная
доступная страница подключения в текущем renderer не заявлены.
