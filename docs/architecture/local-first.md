# Local-First архитектура

Проект Queryn принадлежит пользователю как директория на диске.

Минимальный проект содержит:

- `queryn.json`
- `notes/`
- `assets/`
- `.queryn/`

Приложение не должно полагаться на скрытое удаленное состояние. Производные индексы, кеши и временное состояние размещаются в `.queryn/` и по возможности пересобираются из файлов проекта.

Будущий формат `.osnp` является архивным транспортом для папки проекта. Во время редактирования проекта он не является источником истины.
