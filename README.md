# queryn-docs

Документация Queryn: продукт, архитектура, ADR и правила участия.
Каноническая [страница документации](https://github.com/Queryn-labs/queryn-docs) содержит нормативные страницы и навигацию по проекту.

## Статус

Нормативная документация Queryn: продуктовая доктрина, открытые контракты,
архитектура backend-платформы, политики доверия и ADR. README служит входом в
репозиторий и не дублирует нормативное содержание сайта.

## Stack

- VitePress 1.6.4
- Markdown и TypeScript-конфигурация
- pnpm 10.5.2

## Команды

```bash
pnpm install
pnpm dev
pnpm build
pnpm preview
```

## Границы

- Репозиторий хранит продуктовую рамку, архитектуру, ADR и правила участия.
- Нормативное описание поведения системы находится на сайте документации. Формат
  папки проекта и его JSON Schema определяются в `queryn-spec`.
- Исходники приложений, библиотек, runtime и расширений находятся в соседних
  репозиториях и не дублируются здесь.
- Документация должна быть точной, краткой и привязанной к реализации.
- Решения, затрагивающие несколько репозиториев, фиксируются в ADR.

## Связанные репозитории

- `queryn-spec` описывает открытый folder-based формат проекта.
- `queryn-core` реализует общие TypeScript-примитивы проекта.
- `queryn-desktop` содержит desktop-клиент для Windows и macOS.
- `queryn-sdk` задаёт Developer Kit и контракт расширений.
- `queryn-runtime` является обязательным локальным control plane. AI внутри него опционален.
- `queryn-extensions` содержит каталог и эталонные расширения.
