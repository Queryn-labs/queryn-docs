# Видение продукта

Queryn - local-first модульная среда для учебных и исследовательских проектов,
где обычные файлы, структурированные знания, рабочие сессии и подключаемые
инструменты объединяются в переносимой папке проекта.

Продукт сосредоточен на личном обучении и исследовательской работе:

- Markdown-конспекты для понятий, лекций и кратких материалов.
- Локальные файлы, которые хранятся рядом с проектом.
- Целевая модель структурированных карточек и связей, когда обычных заметок
  недостаточно.
- Рабочие сессии, сохраняющие цель, сообщения, вызовы операций и результаты.
- Целевая модель типизированных артефактов с происхождением и связями.
- Целевая модель инструментов с ручными интерфейсами и объявленными операциями.
- Опциональная AI-оркестрация локальных и облачных моделей.

Инструмент выполняет предметную работу сам. Агент может только подобрать и
вызвать явно объявленную операцию после проверки контекста и policy.

В текущем runtime `queryn.graph.link` записывает отношения через API, но
полноценные графовые и карточные поверхности не поставляются. Нативные заметки
и assets остаются обычными файлами. Descriptor и provenance появляются только
для результатов, которые публикует операция.

Текущий агентный путь использует `agent.chat` и единый диалоговый tool-loop
`AgentKernel`. Отдельный видимый `AgentPlan` и pipeline в продукт не входят.
Учебный план в списке пользовательских результатов означает обычный материал,
который пользователь создаёт вручную или с помощью доступных операций, а не
внутренний план исполнения агента.

Текущая поставка включает папку проекта с заметками и файлами, сессии,
артефакты, созданные операциями, кодовый путь общего ToolWorkspace, ограниченный
Tool Manager и preview проектного контекста. У ToolWorkspace пока нет доступного
маршрута из ProjectNavigator, поэтому ручной запуск операции не считается
завершённым пользовательским потоком. Выбор и прикрепление материалов из
composer, отдельные manual view расширений, специализированные генераторы
карточек, аудио, изображений и схем, а также источники в финальном ответе
относятся к будущему продуктовому слою.

Система сохраняет простой путь очевидным: обычные файлы и заметки, а также
доступные operations через runtime API и CLI полезны без AI, Docker, сети и
сторонних расширений.
