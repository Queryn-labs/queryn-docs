# MVP

> Историческая граница desktop MVP 0.1. Документ не является действующим для Reborn; актуальная последовательность находится в [Roadmap](/product/roadmap).

Первый полезный релиз Osnova должен поддерживать:

- Создание папки проекта с `osnova.json`, `notes/`, `assets/` и `.osnova/`.
- Открытие существующей папки проекта.
- Чтение и валидацию `osnova.json`.
- Просмотр дерева `notes/` и `assets/` с вложенными папками.
- Создание папок внутри `notes/` и `assets/`.
- Создание, открытие, редактирование и сохранение Markdown-конспектов в `notes/`.
- Импорт файлов в `assets/` через drag and drop.
- Вставку wiki-links на статьи и Markdown-ссылок на файлы.
- Preview Markdown с отображением ссылок на статьи и файлы.
- Отображение метаданных проекта и последних конспектов.
- Хранение всех данных проекта в выбранной папке.

Этот срез не требовал packaged extensions и AI. Backend Reborn 0.2 добавляет эти возможности как опциональные слои, сохраняя ручной файловый сценарий.
