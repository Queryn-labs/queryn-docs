# Матрица приёмки просмотрщика материалов

Документ фиксирует пользовательский контракт для встроенного просмотра и
базовой правки. Он нужен до расширения списка форматов, чтобы новый адаптер не
скрывал ошибки в общем запасном представлении.

Компонентные границы, контракт поставщиков и этапы внедрения определены в
[архитектуре просмотрщика](../../architecture/material-viewers.md) и
[ADR 0017](../../adr/adr-0017-material-viewer-host.md).

Названия уровней ниже являются внутренним контрактом команды. Пользователю не
нужно выбирать режим или разбираться в классификации. Он открывает файл и
получает доступные для него действия.

## Уровни поддержки

| Уровень | Что проверяется | Допустимые действия |
| --- | --- | --- |
| Встроенный просмотр | Материал открывается внутри проекта и сохраняет контекст пути | Читать, искать, копировать, листать или менять масштаб по типу материала |
| Базовая правка | Изменяется только поддержанный текстовый исходник | Редактировать, отменить несохранённую правку, сохранить явно |
| Безопасный fallback | Ошибка или отсутствие адаптера не ломает рабочую область | Увидеть имя, путь, тип, размер, повторить чтение, показать в папке, открыть системой |

## Форматы и ожидаемое представление

| Группа | Расширения | Представление | Базовая правка |
| --- | --- | --- | --- |
| Текст и заметки | `md`, `txt`, `log` | Исходный текст, поиск, перенос строк, копирование, номера строк | Да |
| Код | `js`, `jsx`, `mjs`, `ts`, `tsx`, `py`, `java`, `c`, `h`, `cc`, `cpp`, `cxx`, `c++`, `hpp`, `cs`, `rs`, `go`, `kt`, `swift`, `dart`, `rb`, `php`, `sql`, `sh`, `bash`, `zsh`, `ps1` | Подсветка по языку из реестра, поиск, номера строк, копирование | Да |
| Структурированный текст | `json`, `jsonl`, `xml`, `yaml`, `yml`, `toml` | Исходник и, где возможно, дерево или форматированный вид. Ошибка оставляет сырой текст | Да |
| Табличный текст | `csv`, `tsv` | Заголовки, строки, разделитель, ограниченный фрагмент и исходник | Да |
| Веб-материалы | `html`, `htm`, `css` | Исходник. HTML дополнительно показывается статически в изолированном представлении | Да |
| Изображения | `png`, `jpg`, `jpeg`, `gif`, `webp`, `svg` | Подложка, масштаб и вписывание. SVG не выполняет сценарии | Нет |
| Документы | `pdf` | Страницы, листание, номер страницы, масштаб, поиск и текстовый слой | Нет |
| Данные | `parquet` | Схема, типы, число строк и небольшой фрагмент строк | Нет |
| Таблицы | `xlsx`, `xls` | Листы и ограниченная сетка только для чтения | Нет |
| Документы и презентации | `docx`, `pptx` | Приближённое извлечение текста, страниц или слайдов | Нет |
| Ноутбуки | `ipynb` | Просмотр ячеек и сохранённых результатов без запуска ядра | Нет |
| Прочее | Архивы, аудио, видео, неизвестные бинарные файлы | Метаданные и системное открытие | Нет |

## Обязательные состояния

Каждый адаптер должен иметь проверяемые состояния:

- загрузка с признаком занятости и сохранением фокуса;
- пустой файл с объяснением, что содержимого нет;
- слишком большой файл с ограниченным фрагментом или только метаданными;
- ошибка чтения или разбора с причиной и повтором;
- неизвестный тип с расширением и системным открытием;
- несовпадение расширения и содержимого с предупреждением и безопасным видом;
- повреждённый контейнер с fallback без падения всего просмотрщика;
- несохранённая правка с выбором сохранить, отменить или продолжить без сохранения.

## Приёмочная матрица

| Область | Fixture или действие | Ожидаемый результат |
| --- | --- | --- |
| Реестр | Расширение в нижнем и верхнем регистре | Выбран один и тот же тип и язык |
| Реестр | `.c`, `.h`, `.cc`, `.cpp`, `.cxx`, `.hpp`, `.c++` | C и C++ различаются по правилам реестра |
| Реестр | Нет расширения, неизвестное расширение, неверный MIME | Нейтральная иконка, понятный тип и fallback |
| Реестр | Текстовый файл с расширением изображения или бинарный файл с расширением текста | Сигнатура и содержимое не приводят к опасному представлению |
| Кодировка | UTF-8, UTF-8 с BOM, UTF-16, Windows-1251, кириллица в пути | Текст читается или явно объясняется неподдержанная кодировка |
| Текст | Пустой файл, длинная строка, файл больше лимита | Нет зависания, показывается состояние размера или пустого содержимого |
| JSON и XML | Валидный файл, битый файл, внешний DTD или сущности | Дерево для валидного, сырой текст для ошибки, внешние сущности не загружаются |
| CSV и TSV | Кавычки, перенос строки внутри ячейки, разные разделители, битая строка | Таблица с заголовками или понятный сырой fallback |
| HTML | Сценарий, форма, внешний `img`, внешний CSS, локальная ссылка | Статический вид без выполнения сценариев, сети и отправки формы |
| PDF | Валидный файл, повреждённый файл, несколько страниц | Листание и текстовый слой или внешний fallback |
| Office | Валидный и повреждённый `docx`, `pptx`, `xlsx` | Приближённый просмотр или внешний fallback, viewer не падает |
| Parquet | Валидная схема, кодек без поддержки, повреждённый footer | Схема и фрагмент строк или объяснимый fallback |
| Безопасность | Путь с `..`, символическими ссылками, нет доступа | Файл не выходит за пределы проекта, ошибка видима пользователю |
| Навигация | Поиск по имени, пути и типу, фильтры материалов | Дерево действительно фильтруется, совпадения сохраняют путь |
| Доступность | Клавиатура, фокус, светлая и тёмная тема, уменьшение анимации | Видимый фокус, роли дерева и таблицы, достаточный контраст, без потери фокуса |
| Правка | Изменить текст, отменить, сохранить, повторно открыть | Файл изменён только после явного сохранения, результат читается снова |
| Конфликт | Изменить исходный файл вне Queryn при открытом локальном буфере | Буфер не потерян, тихой перезаписи нет, доступны перечитать, сохранить копию или заменить после подтверждения |
| Поставщик | Удалить или отключить расширение выбранного адаптера | Материал открывается встроенным адаптером или безопасным fallback |
| Поставщик | Запустить специализированный просмотр подключённого расширения | Вызов проходит через operation, Job Manager и policy, runtime получает snapshot без пути проекта |
| Получатель | Открыть файл с доступным remote provider без сохранённого согласия | Файл не отправляется автоматически, используется встроенный fallback и доступно явное включение provider |
| Авария поставщика | Остановить внешний парсер во время открытия | Ошибка локальна, дерево и другие материалы доступны, показан номер диагностики |
| Ресурсы | Передать архив с чрезмерной распаковкой или глубиной | Разбор остановлен по лимиту, временные данные очищены, проект не изменён |

## Ограничения и безопасность

Просмотрщик не запускает код, JavaScript, макросы, внешние формы и сетевые
запросы. HTML открывается только как статический изолированный материал. SVG
обрабатывается как потенциально активный ресурс и не получает доступ к
привилегированному контексту. Парсеры документов и таблиц работают с лимитом
размера и не должны распаковывать архивы в произвольные пути.

Большие файлы читаются ограниченными фрагментами или через отдельный ресурс,
а не целиком в строку или ссылку с данными. Ошибка одного файла не очищает
дерево, заметку и другие открытые материалы.

## Результат проверки

Адаптер считается готовым, когда прошёл матрицу формата, состояния, клавиатуры,
двух тем, безопасного fallback и повторного открытия после правки. До этого
формат считается экспериментальным и должен сохранять системное открытие.
