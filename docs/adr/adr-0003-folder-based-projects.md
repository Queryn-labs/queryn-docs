# ADR 0003: Folder-based проекты

## Статус

Принято.

## Контекст

Учебные проекты должны оставаться долговечными вне приложения и совместимыми с обычными инструментами backup, sync и version control.

## Решение

Проект Osnova является обычной папкой с manifest, Markdown-конспектами, файлами и опциональными структурированными данными.

## Последствия

Формат проекта должен быть публично документирован. Desktop-функции должны считать папку источником истины. Архивные форматы вроде `.osnp` являются транспортными форматами, а не основной моделью редактирования.
