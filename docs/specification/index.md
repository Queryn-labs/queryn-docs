# Спецификация

Авторитетное описание формата проекта находится в `osnova-spec`.

Этот раздел кратко фиксирует контракт формата `0.2`:

- Проект является папкой.
- `osnova.json` является manifest и объявляет версию формата.
- `notes/` содержит Markdown-конспекты.
- `assets/` содержит пользовательские файлы.
- `artifacts/` содержит описатели типизированных результатов и их payloads.
- `sessions/` содержит переносимые рабочие сессии.
- `relations/` содержит связи между артефактами.
- `.osnova/` содержит application metadata, кеши и индексы.

Проекты формата `0.1` остаются читаемыми; переход в `0.2` выполняется явной
миграцией с dry-run и backup manifest.
