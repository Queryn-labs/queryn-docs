# ADR 0014: Windows и macOS как равноправные desktop-цели

## Статус

Принято.

## Контекст

Первоначальная формулировка Windows-first отражала приоритет первого запуска,
но больше не описывает продуктовую границу. Текущий desktop-код уже учитывает
Windows и macOS в процессе создания окна, системной панели и завершении
приложения. Основные project, runtime и renderer-сценарии общие для обеих
платформ.

## Решение

Windows и macOS являются равноправными целевыми платформами Osnova desktop.
Платформенные различия реализуются только там, где они требуются системной
оболочкой. На macOS сохраняются native titlebar и стандартный жизненный цикл
окон, на Windows используется собственная панель окна и обычное завершение
приложения при закрытии последнего окна.

Пути проекта, формат `osnova.json`, локальный runtime RPC, preload bridge и
основные renderer-фичи не получают раздельных продуктовых контрактов по
платформам.

## Последствия

ADR 0001 сохраняется как история первоначального запуска и помечается
заменённой. Сборка, проверка и ручные сценарии desktop должны учитывать обе
платформы. Новое поведение, которое действительно зависит от ОС, должно быть
ограничено main-слоем или адаптером оболочки и не должно переносить различия в
формат проекта или renderer API.
