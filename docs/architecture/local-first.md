# Local-First архитектура

Проект Osnova принадлежит пользователю как директория на диске.

Минимальный проект содержит:

- `osnova.json`
- `notes/`
- `assets/`
- `.osnova/`

Приложение не должно полагаться на скрытое удаленное состояние. Производные индексы, кеши и временное состояние размещаются в `.osnova/` и по возможности пересобираются из файлов проекта.

Будущий формат `.osnp` является архивным транспортом для папки проекта. Во время редактирования проекта он не является источником истины.
