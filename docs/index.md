# Queryn

Queryn — local-first модульная среда для учебных и исследовательских проектов.
Пользователь работает с обычной папкой, в которой хранятся заметки, материалы,
сессии и результаты инструментов. Desktop-клиент помогает видеть эту структуру,
а локальный runtime выполняет операции и опционально подключает агентный слой.

Windows и macOS являются равноправными desktop-целями. Папка проекта остаётся
источником истины, а облачные модели, сеть и расширения являются подключаемыми
возможностями.

   [аудиторию и Jobs-to-be-Done](/product/jobs-and-non-goals), чтобы увидеть,
   для кого строится продукт и какие задачи остаются за его пределами.
3. Откройте [обзор архитектуры](/architecture/overview), затем сверяйтесь с
   [архитектурой desktop-клиента](/architecture/desktop), если нужен путь от

4. Проверьте [спецификацию формата проекта](/specification/), если меняете
   manifest, папки, артефакты или сессии.
5. Для долгосрочных границ перейдите в [журнал архитектурных решений](/adr/),
   а правила публикации изменений смотрите в [уставе документации](/guidelines).

## Глоссарий

- **Проект** — обычная папка с `queryn.json`, материалами, артефактами и
  переносимыми сессиями.
- **Манифест** — файл `queryn.json`, который задаёт идентификатор, имя, тип,
  версию формата и требования к расширениям проекта.
- **Артефакт** — описанный результат операции с payload-файлом и происхождением.
- **Сессия** — журнал отдельной задачи или диалога внутри проекта.
- **Operation** — зарегистрированное вызываемое действие с входной и выходной
  схемами, разрешениями и оценкой риска.
- **Tool** — пользовательская возможность, которая выполняет одну или несколько
  операций через runtime API, CLI или запрос агента. Универсальная ручная
  поверхность в текущем desktop ещё не выведена в навигацию.
- **Extension** — пакет расширения с manifest, contributions, разрешениями и
  управляемой средой выполнения.
- **Envelope** — ограниченный пакет контекста с источниками, чувствительностью,
  получателями, бюджетом и признаком усечения.
- **Approval** — явное решение пользователя на действие, требующее разрешения.
- **Агент** — диалоговый tool-loop, который выбирает доступные операции,
  соблюдает policy и сохраняет события и результаты в сессии.
- **Queryn** — продукт, desktop-оболочка и агентный интерфейс, работающие с
  одной папкой проекта как источником истины.

## Репозитории

- `queryn-docs` — продуктовая, архитектурная и ADR-документация.
- `queryn-spec` — открытый формат проекта и JSON Schema.
- `queryn-core` — общие TypeScript-библиотеки для project IO и валидации.
- `queryn-desktop` — desktop-клиент на Electron, React и TypeScript.
- `queryn-sdk` — TypeScript SDK для расширений.
- `queryn-runtime` — обязательный локальный control plane с опциональным AI.
- `queryn-extensions` — каталог и эталонные расширения.
